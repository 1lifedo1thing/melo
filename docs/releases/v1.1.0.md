# Melo 1.1.0 — More to discover

This release makes Home a more personal place to find something to play, adds a richer podcast experience, and brings the app's screens into a more consistent visual style.

## Home and discovery

- Browse mood-led recommendations and refresh Home picks together with Speed Dial.
- Move between Speed Dial, Artist Dial, and Mixes, with controls for sources, grid size, tile labels, and appearance.
- Keep pinned items, recent listening, and discovery picks easier to scan with compact shelves and consistent cards.
- See loading placeholders while recommendations refresh, without losing the existing Home content.
- Use the Lucky and History tiles even when a Speed Dial page has only a few items.

## Podcasts

- Browse podcast shows and episodes in a dedicated Podcasts area.
- Search for shows and episode titles from within Podcasts.
- See podcast recommendations and search results with consistent artwork and card sizing.

## App-wide refinements

- Apply a more consistent type, spacing, surface, and card style across Home, Library, Search, playlists, and Settings.
- Refine the player artwork presentation while keeping Melo's playback controls and gestures.
- Open Home settings in a rounded overlay that leaves the page in place and dismisses when tapped outside.
- Use the device's region for YouTube Music recommendations without a country selector in Settings.

## Install

Download **Melo-v1.1.0.apk** and install it on an ARM64 Android device running Android 8.0 or later. Android will ask you to approve installation.

The GitHub release includes the APK. GitHub also provides the matching **Source code (zip)** and **Source code (tar.gz)** archives for the release tag.
