# Melo 1.0.0

The first public Melo release brings the native Android player under the **in.melo** app ID, with the dot-matrix Melo identity, a quieter monochrome interface, colourful music artwork, and the refined welcome page.

## In this release

- Spotify, YouTube Music, and local audio in one listening app.
- Library, playlists, queue, lyrics, downloads, history, and equalizer tools.
- In-app checks for future stable releases from the Melo GitHub repository.

## Install

Download **Melo-v1.0.0.apk** below and install it on an ARM64 Android device running Android 8.0 or later. Android will ask you to approve installation.

The app is signed with Melo's release certificate. Keep that signing key backed up: future APK updates must use the same key and a higher version code.

## Verification

The APK signature was verified with Android's apksigner. The companion checksum file identifies the APK:

    938ff4c8fbce4513a9bb586de8355ad4c499a512f3e894f37189bf539bc586dd  Melo-v1.0.0.apk

Melo's Spotify integration uses the native Android protocol and a locally prepared runtime from the unmodified Spotify 9.2.0.26 ARM64 client archive. The source repository contains no runtime binaries. A successful build does not establish live encrypted playback; see the protocol evidence for what has and has not been verified.
