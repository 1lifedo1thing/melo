# Changelog

## Melo 1.0.0 — Public launch

- Release Melo as a standalone Android app with the in.melo application ID.
- Publish the complete application source and signed ARM64 APK.
- Connect in-app update checks to Melo's public GitHub Releases feed.
- Bring the dot-matrix identity, monochrome interface, colourful artwork, and refined start page together in one release.
